## 🚀 Sobre o Projeto

A aplicação consiste em uma Pokédex que consome dinamicamente a [PokéAPI](https://pokeapi.co/) para listar os Pokémon com seus respectivos tipos, números e imagens, permitindo o carregamento contínuo através de paginação.

### 🌟 Funcionalidades e Diferenciais
- **Detalhamento do Pokémon**: Exibição das estatísticas e informações detalhadas ao selecionar um Pokémon.
- **Paginação Dinâmica**: Botão "Load More" para carregar novas gerações de Pokémon sob demanda.
- **Design Responsivo**: Estilização com CSS3 adaptada para telas móbile e desktop.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, Flexbox, CSS Grid e variáveis customizadas para as cores dos tipos de Pokémon.
- **JavaScript (ES6+)**: Lógica da aplicação, manipulação do DOM e integração com a PokéAPI.
